# arbachin-design

আরবাচীন (Arbachin) — Luxury Handcrafted Sarees & Ensembles E-Commerce Website.

## 🌟 Overview
A haute couture fashion e-commerce storefront inspired by the luxury aesthetics of Sabyasachi and Ritu Kumar. Built with modern HTML5, CSS3, Tailwind CSS v4, and Vanilla JavaScript.

## 📁 Pages Included
- **Home Page (`index.html`)**: Cinematic hero, marquee banner, curated category showcases, featured products grid, atelier heritage story, patron testimonials, VIP newsletter, and slide-over shopping bag drawer.
- **Category Page (`category.html`)**: Responsive sidebar filters (Category, Fabric, Price Range Slider, Color Palette), dynamic sorting, grid view switcher, product counts, and empty state management.
- **Product Details Page (`product.html`)**: High-resolution zoomable image gallery, color/fabric selectors, quantity controls, interactive accordions (Craftsmanship, Care, Delivery), and related product recommendations.

## 🎨 Tech Stack & Design System
- **Technologies**: HTML5, Vanilla CSS, Tailwind CSS v4 CDN, Vanilla JavaScript
- **Brand Colors**: Deep Forest Green (`#1a3c2a`), Antique Gold (`#c9a84c`), Warm Cream (`#f0ebe1`), Obsidian Dark (`#0f1a14`)
- **Typography**: Playfair Display (Headings), Cinzel (Badges & Accents), Plus Jakarta Sans (Body)
- **Features**: Real-time Cart Management, Wishlist, Instant Global Search Modal, Quick View Modal, Toast Notification Engine.
